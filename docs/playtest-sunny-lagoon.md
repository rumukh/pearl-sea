# Slunná laguna playtest (3rd grader)

A one-page checklist for the grown-up who plays the slice with the child. The aim is to see how a
child really meets the game, not to teach it: say as little as you can, and write down what you
see.

## Before you start (10 minutes, without the child)

1. **Device.** The family tablet in landscape, or the PC. On an iPad, check Settings › General ›
   About: music needs iPadOS 18.4 or later (older iPads play silently; everything else works).
   Charge it, turn the volume to about half, and close other apps.
2. **Open the game**: https://rumukh.github.io/pearl-sea/ in Safari, Chrome or Edge. On a tablet,
   Share › Add to Home Screen gives the game the whole screen.
3. **Read-aloud voice** (optional; the game works fully without it). iPad: Settings ›
   Accessibility › Spoken Content › Voices › Czech › Zuzana (download it). Windows: Settings ›
   Time & language › Speech › Add voices › Czech. Then reopen the game.
4. **The grown-ups' area**: on the title tap **Pro dospělé** (top right), hold the lock for two
   seconds, answer the multiplication. Under **Nastavení** it says whether a Czech voice was found.
   You can switch this area to English there.
5. **Optional, offline**: Pro dospělé › Bez internetu › Nainstalovat, so the game runs without
   Wi-Fi.
6. **Let the child make their own profile** in the game (tap **Hrát**): a name, a picture,
   kluk / holka / nechci říct, **3. třída**. Afterwards, in Pro dospělé › Nastavení you can turn on
   "Číst nové úlohy nahlas automaticky" and set the music volume or the text size.

Known gaps (not the child's fault, not worth noting): shapes labelled "DEV …" are pictures still
being painted; there are no sound effects yet (only music, once the current fix lands).

## While the child plays (about 15-20 minutes; stop when they want to)

Sit beside them. Answer questions briefly; do not explain an activity before they try it. Note the
minute when something happens. Watch for:

| What                                                                | Notes (yes / no, what happened) |
| ------------------------------------------------------------------- | ------------------------------- |
| Makes the profile alone? Which step needed help?                    |                                 |
| Reads the story or skips it (Přeskočit)? Uses the speaker button?   |                                 |
| Which egg do they choose, and why?                                  |                                 |
| Finds Dnešní výprava without help?                                  |                                 |
| **Perlový náhrdelník**: understands how to move the pearls?         |                                 |
| **Rybářské sítě**: taps or drags the fish? Knows the three nets?    |                                 |
| **Krmení**: understands the ink blot and the letter choice?         |                                 |
| After a miss ("Skoro!"): reads the right answer and the tip? Upset?  |                                 |
| Uses **Nápověda** (the hint)? Does it help?                         |                                 |
| **Inkoustová věta**, **Lov chyb**: understands without help?        |                                 |
| **Pexeso**: works out what makes a pair?                            |                                 |
| The friend hatching: excited? Says the friend's name?               |                                 |
| Finds the map, U Mrože, Kamarádi, the album (scrolls down to them)? |                                 |
| Buys or dresses something?                                          |                                 |
| **Muréna Mumla's battle**: fun or scary? Wipes the ink blots? Jokes? |                                 |
| Where do they hesitate, skip or tap at random?                       |                                 |
| Moments of joy (laughs, "jé!") and of frustration (sighs, wants to stop) |                            |
| Reading: too much text anywhere? Words they cannot read?            |                                 |
| Anything a grown-up had to do for them (exact words help)           |                                 |
| When did attention drop (minutes)?                                   |                                 |

## Afterwards: ask the child (in Czech, casually)

- Co tě na hře nejvíc bavilo?
- Bylo něco těžké, nebo nudné? Co?
- Věděl/a jsi vždycky, co máš udělat? Kdy ne?
- Kterého kamaráda máš nejradši? Proč?
- Jaká byla muréna Mumla? Bál/a ses jí, nebo byla legrační?
- Pomohla ti Nápověda, když jsi nevěděl/a?
- Chtěl/a bys zítra hrát znovu? Co bys chtěl/a v moři ještě potkat?
- Kdybys mohl/a ve hře něco změnit, co by to bylo?

## Reporting back

Send your notes to the coordinator session: the table above (a photo of the paper is fine), the
child's answers in their own words, the device and browser, and screenshots of anything that
looked wrong. The game keeps everything on the device; to send us the child's save as well, use
Pro dospělé › Zálohy › Uložit zálohu and attach the file.
